Política de privacidade

O Jarvis é um projeto de uso pessoal mantido por Lucas Corrêa. Esta política descreve como o projeto trata os dados da integração com o Gmail.

Dados acessados

Ao conectar a caixa dedicada, o titular concede ao Jarvis permissão para ler mensagens e configurações dessa caixa pela Gmail API. A integração verifica o endereço autorizado, busca identificadores de mensagens e pode ler remetente, assunto, data e o conteúdo dos avisos necessários para extrair informações.

Finalidade e armazenamento

O Jarvis usa esses dados para identificar avisos recebidos, organizar informações e acompanhar os eventos selecionados pelo titular. As credenciais da integração e os registros necessários ao acompanhamento ficam em armazenamento com acesso restrito. Mensagens originais permanecem no Gmail. O painel privado e o canal de avisos escolhido pelo titular podem exibir os campos necessários sobre um evento.

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

Revogação e exclusão

Para interromper o acesso, remova a conexão do Jarvis nas conexões de terceiros da Conta Google. Para solicitar a exclusão de dados mantidos na integração ou tirar dúvidas, escreva para automacoes.jarvis@gmail.com.
